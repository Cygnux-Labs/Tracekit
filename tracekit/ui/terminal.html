COMMANDS · type then press ENTER (GO)

AGT <text> Show one agent: matches id, type or task description
TOOL <name> Only this tool (BASH, READ, EDIT, AGENT, MCP…)
FILE <text> Only actions touching matching paths
FLAG Only flagged, blocked or failed actions (toggle)
FIND <text> Full-text search across inputs, outputs and reasoning
SEQ <n> Open ledger record n in DETAIL
CLR Clear all filters
PAUSE · PLAY · SPEED <n> Replay controls
SPACE · ← → · D H G · L v2 runs (tracekit view), with a run selected: replay play/pause, step one record, next deny / hold / gap, back to live (also ESC)
DESK · RUNS · OVERVIEW · TIMELINE · WHY DID IT HAPPEN? · GRAPH · AGENTS · INFLUENCE With why logs (header buttons): a why view in place of the lower panels; DETAIL · WHY · NODE: the selected record, why the selected call happened, the clicked node

A row is a signed record of the hash-chained ledger unless it says ANALYSIS (the viewer's own verification and findings: no seq, no hash, not evidence) or WHY (a why log). DETAIL shows a record's seq, hash and previous hash. Times are this browser's local time. Reasoning is what the model reported about itself; actions are what it did.
