# Invariants → tests

Each invariant of the v2 design names the tests that enforce it. `tests/test_invariants_map.py` fails when an
invariant is missing from this table, names no test, or names a test that does not exist. Some tests named here skip
off Linux or without root; CI runs them on Linux. The evals in `eval/` (E4 v2, E8 v2, E9, E11, E12, E15) check the same
promises end to end and are listed in `docs/evaluation.md`.
