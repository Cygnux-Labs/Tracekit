COMMANDS · type then press ENTER (GO)

AGT <text>Show one agent: matches id, type or task description
TOOL <name>Only this tool (BASH, READ, EDIT, AGENT, MCP…)
FILE <text>Only actions touching matching paths
FLAGOnly flagged, blocked or failed actions (toggle)
FIND <text>Full-text search across inputs, outputs and reasoning
SEQ <n>Open ledger record n in DETAIL
CLRClear all filters
PAUSE · PLAY · SPEED <n>Replay controls

Every row is a record in the hash-chained ledger. DETAIL shows its seq, hash and previous hash. Reasoning is what the model reported about itself; actions are what it did.
